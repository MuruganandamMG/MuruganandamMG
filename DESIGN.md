# Visual résumé design

The supplied reference establishes the stacked image-card format and theme switching. The replacement is an editorial engineering résumé, with direct factual writing and no simulated shell window, terminal commands, skill percentages, or decorative metrics.

- Space Grotesk display type, Manrope body type. Text becomes vector outlines for consistent rendering inside GitHub images; fonts and their OFL licenses are bundled.
- Dark: deep blue-black paper, soft white text, mint accents. Light: warm white paper, deep teal text, evergreen accents. Flat surfaces with fine rules and 16px corners.
- Wide desktop compositions and separately composed 480px mobile artwork. Body text stays at least 18px in the source artwork; image widths follow the available README space.
- Identity and engineering flow; experience timeline; four linked work panels; technical toolkit; education and credentials; contact. Activity is optional and secondary.
- Motion is limited to the hero's context/plan/build/validate flow and the current-role indicator. Content remains visible with motion disabled. Respect prefers-reduced-motion in every animated asset.
- Every image has descriptive alternative text; a full native Markdown résumé provides selectable text and semantic headings. Links live outside SVGs so they remain interactive on GitHub.
